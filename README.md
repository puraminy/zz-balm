# Lemon Balm Corrosion Inhibitor — Headless Reproducibility Pipeline

Docker-first, command-line-only workflow for auditing and reimplementing computational methods from Asadi et al. (2018), DOI: 10.1016/j.jtice.2018.07.011.

This repository is an initial scaffold, not yet a completed scientific reproduction. It is designed for headless tools and does not require GUI applications. Proprietary Gaussian 09 and Materials Studio components are not bundled; open-source alternatives must be reported as methodologically different unless validated otherwise.
